# 📚 CMIS数据合并工具

一个基于 Streamlit 的Web应用，用于将两个Excel文件中顺序不同的数据合并起来。

## 功能特点

- ✅ **Excel导入**：支持导入.xlsx和.xls格式的Excel文件
- 🔍 **智能识别**：自动识别姓名、学号、班级列，支持手动调整
- 🆔 **自动生成学号**：如果没有学号列，自动生成唯一标识符
- 🔄 **数据合并**：根据姓名或学号匹配，将两个Excel文件中的数据进行合并
- 📋 **列映射**：支持自定义列映射，灵活处理不同格式的Excel文件
- ✏️ **数据编辑**：支持在表格中直接编辑数据
- 💾 **数据导出**：导出合并后的结果到Excel文件

## 安装步骤

1. **创建虚拟环境**（推荐）
   ```bash
   python3 -m venv venv
   ```

2. **激活虚拟环境**
   
   macOS/Linux:
   ```bash
   source venv/bin/activate
   ```
   
   Windows:
   ```bash
   venv\Scripts\activate
   ```

3. **安装依赖**
   ```bash
   # 使用国内镜像源（推荐，速度更快）
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   
   # 或者直接使用（启动脚本已自动配置镜像源）
   pip install -r requirements.txt
   ```
   
   **配置永久镜像源**（可选）：
   - macOS/Linux: 创建 `~/.pip/pip.conf` 文件，内容参考项目中的 `pip.conf`
   - Windows: 创建 `%APPDATA%\pip\pip.ini` 文件

4. **运行应用**
   ```bash
   streamlit run app.py
   ```
   
   或者使用启动脚本：
   
   macOS/Linux:
   ```bash
   ./start.sh
   ```
   
   Windows:
   ```bash
   start.bat
   ```

5. **访问应用**
   浏览器会自动打开，或手动访问 `http://localhost:8501`

6. **退出虚拟环境**（完成后）
   ```bash
   deactivate
   ```

## 使用方法

### 1. 导入基准文件

- 在左侧边栏上传第一个Excel文件（作为基准顺序）
- **文件预览**：上传后会显示文件预览，方便确认数据
- **列映射设置**：
  - **姓名列**（必选）：选择包含姓名的列
  - **学号列**（可选）：如果有学号列，选择对应列；如果没有，系统会自动生成唯一标识符（格式：班级_序号 或 STU_序号）
  - **班级列**（可选）：如果有班级列，选择对应列
- Excel文件列识别支持：
  - **姓名**：姓名、名字、Name
  - **学号**：学号、编号、ID、student_id
  - **班级**：班级、class、班、教学班、行政班
- 点击"加载学生名单"按钮

### 2. 导入并合并第二个Excel文件

- 在主界面中上传第二个Excel文件（包含需要合并的数据）
- 选择**匹配列**：用于匹配两个文件的列（建议使用学号列，可避免重名问题）
- 选择**要合并的列**：选择需要从第二个文件中合并到基准文件的列（可多选）
- 点击"导入成绩列"按钮完成合并
- 系统会根据匹配列自动匹配两个文件中的数据，即使顺序不同也能正确合并

### 3. 编辑数据

- 在表格中直接编辑数据
- 使用Tab键快速切换单元格
- 点击"保存更改"保存修改

### 4. 导出结果

- 在左侧边栏点击"导出Excel"按钮
- 下载包含合并后所有数据的Excel文件

## Excel文件格式示例

### 示例1：包含学号和班级
| 学号 | 姓名 | 班级 |
|------|------|------|
| 2021001 | 张三 | 计算机1班 |
| 2021002 | 李四 | 计算机1班 |
| 2021003 | 王五 | 计算机2班 |

### 示例2：只有姓名和班级（无学号）
| 姓名 | 班级 |
|------|------|
| 张三 | 计算机1班 |
| 李四 | 计算机1班 |
| 王五 | 计算机2班 |

系统会自动为没有学号的学生生成唯一标识符（如：计算机1班_001）

### 示例3：只有姓名（最简单）
| 姓名 |
|------|
| 张三 |
| 李四 |
| 王五 |

系统会自动生成标识符（如：STU_0001）

## 技术栈

- **Streamlit**：Web应用框架
- **Pandas**：数据处理
- **OpenPyXL**：Excel文件处理

## 注意事项

- 匹配列建议使用学号列，可避免因重名导致的匹配错误
- 如果使用姓名列匹配且存在重名情况，系统会提示您选择对应的记录
- 支持跳过文件头部和尾部的无用行（如标题、说明、汇总等）
- 数据会自动保存到本地，刷新页面不会丢失
- 支持导入多个成绩列，每个列都会作为独立的列添加到数据中
