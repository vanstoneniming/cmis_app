# 📚 CMIS成绩处理辅助工具

一个基于 Streamlit 的Web应用，用于快速录入和统计学生成绩。

## 功能特点

- ✅ **Excel导入**：支持导入.xlsx和.xls格式的学生名单
- 🔍 **智能识别**：自动识别姓名、学号、班级列，支持手动调整
- 🆔 **自动生成学号**：如果没有学号列，自动生成唯一标识符
- 📝 **批量录入**：支持批量录入作业评分和状态
- ✏️ **单个编辑**：支持搜索并编辑单个学生的作业信息（可按学号、姓名、班级搜索）
- 📊 **实时统计**：自动统计已提交/未提交学生数量和平均分
- 📚 **班级统计**：支持按班级查看未提交学生分布
- 💾 **数据导出**：导出统计结果到Excel文件

## 安装步骤

1. **创建虚拟环境**（推荐）
   ```bash
   python3 -m venv venv
   ```

2. **激活虚拟环境**
   
   macOS/Linux:
   ```bash
   source venv/bin/activate
   ```
   
   Windows:
   ```bash
   venv\Scripts\activate
   ```

3. **安装依赖**
   ```bash
   # 使用国内镜像源（推荐，速度更快）
   pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   
   # 或者直接使用（启动脚本已自动配置镜像源）
   pip install -r requirements.txt
   ```
   
   **配置永久镜像源**（可选）：
   - macOS/Linux: 创建 `~/.pip/pip.conf` 文件，内容参考项目中的 `pip.conf`
   - Windows: 创建 `%APPDATA%\pip\pip.ini` 文件

4. **运行应用**
   ```bash
   streamlit run app.py
   ```
   
   或者使用启动脚本：
   
   macOS/Linux:
   ```bash
   ./start.sh
   ```
   
   Windows:
   ```bash
   start.bat
   ```

5. **访问应用**
   浏览器会自动打开，或手动访问 `http://localhost:8501`

6. **退出虚拟环境**（完成后）
   ```bash
   deactivate
   ```

## 使用方法

### 1. 导入学生名单

- 在左侧边栏上传Excel文件
- **文件预览**：上传后会显示文件预览，方便确认数据
- **列映射设置**：
  - **姓名列**（必选）：选择包含学生姓名的列
  - **学号列**（可选）：如果有学号列，选择对应列；如果没有，系统会自动生成唯一标识符（格式：班级_序号 或 STU_序号）
  - **班级列**（可选）：如果有班级列，选择对应列，可以在统计时按班级查看
- Excel文件列识别支持：
  - **姓名**：姓名、名字、Name
  - **学号**：学号、编号、ID、student_id
  - **班级**：班级、class、班、教学班、行政班
- 点击"加载学生名单"按钮

### 2. 录入作业评分

**批量录入模式：**
- 在表格中直接编辑每个学生的作业状态、评分和备注
- 使用批量操作功能快速标记所有学生
- 点击"保存更改"保存修改

**单个编辑模式：**
- 搜索学生（支持学号或姓名）
- 选择要编辑的学生
- 修改作业状态、评分和备注
- 点击"保存"保存修改

### 3. 查看统计

- 查看总体统计信息（总学生数、已提交/未提交数量、平均分）
- 查看未提交学生列表
- 查看已提交学生的详细信息和分数分布

### 4. 导出结果

- 在左侧边栏点击"导出Excel"按钮
- 下载包含所有统计信息的Excel文件

## Excel文件格式示例

### 示例1：包含学号和班级
| 学号 | 姓名 | 班级 |
|------|------|------|
| 2021001 | 张三 | 计算机1班 |
| 2021002 | 李四 | 计算机1班 |
| 2021003 | 王五 | 计算机2班 |

### 示例2：只有姓名和班级（无学号）
| 姓名 | 班级 |
|------|------|
| 张三 | 计算机1班 |
| 李四 | 计算机1班 |
| 王五 | 计算机2班 |

系统会自动为没有学号的学生生成唯一标识符（如：计算机1班_001）

### 示例3：只有姓名（最简单）
| 姓名 |
|------|
| 张三 |
| 李四 |
| 王五 |

系统会自动生成标识符（如：STU_0001）

## 技术栈

- **Streamlit**：Web应用框架
- **Pandas**：数据处理
- **OpenPyXL**：Excel文件处理

## 注意事项

- 作业状态包括："未提交"、"已提交"
- 评分范围：0-100分
- 只有标记为"已提交"的学生才能录入评分
- 数据保存在浏览器会话中，刷新页面会丢失，建议及时导出
